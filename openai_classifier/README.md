# OpenAI Classifier Adapter

Adapter for [openai/gpt-4o-mini](https://platform.openai.com/docs/models/gpt-4o-mini).

## Overview
Uses GPT-4o-mini via the OpenAI API for general-purpose text classification.

## Model details
- **Model:** openai/gpt-4o-mini
- **Task:** classify
- **Domain:** general
- **Language:** TypeScript
- **License:** MIT

## Output schema
Returns a classification label and confidence score as defined by the prompt.

## Usage
See [openai-classifier.ts](openai-classifier.ts) for the full implementation.
